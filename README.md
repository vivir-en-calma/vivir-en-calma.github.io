# Vivir en calma

Cartilla interactiva del Proyecto Libélula: una guía para cuidar mi cuerpo, mis
emociones y mi bienestar. Siete módulos para comprender la hipertensión y la
diabetes desde el cuerpo y las emociones, con ejercicios para practicar.

Es un sitio estático: no tiene registro de usuarios ni guarda datos en servidores.
Lo que cada persona escribe en los ejercicios queda solo en su dispositivo.

Se publica automáticamente en GitHub Pages al subir cambios a la rama `master`.
